## ⚠️ ملاحظة مهمة عن مصدر البيانات

بيانات المرضى والصور ونتائج التحليل الموجودة حالياً في `database/skin_cancer.db`
هي **بيانات اصطناعية (Synthetic)** تم توليدها بواسطة `database/seed_data.py`
لأغراض العرض واختبار بنية النظام فقط — **وليست بيانات مرضى حقيقيين**.

تم توليدها بحيث تحاكي **نسب التوزيع الحقيقية** لفئات الآفات الجلدية السبع
كما نُشرت في الورقة العلمية الأصلية لمجموعة بيانات **HAM10000**
(Tschandl, Rosendahl & Kittler, 2018 — "The HAM10000 dataset"):

| الفئة | الاسم | النسبة في HAM10000 الأصلية | خطيرة؟ |
|---|---|---|---|
| nv | شامة عادية | 67.0% (6705 صورة) | لا |
| mel | الميلانوما | 11.1% (1113 صورة) | نعم |
| bkl | توسّف حميد | 11.0% (1099 صورة) | لا |
| bcc | سرطان الخلايا القاعدية | 5.1% (514 صورة) | نعم |
| akiec | توسّف شعاعي | 3.3% (327 صورة) | نعم |
| vasc | آفة وعائية | 1.4% (142 صورة) | لا |
| df | ورم ليفي جلدي | 1.1% (115 صورة) | لا |

الصور نفسها (ملفات .jpg) **غير موجودة فعلياً** — الأعمدة `image_path` في جدول
`images` هي مسارات وهمية توضّح شكل البيانة فقط. الخطوة القادمة الحقيقية هي
تحميل الصور الفعلية من Kaggle أو ISIC Archive (راجعي `src/01_data_exploration.py`
للتعليمات) واستبدال البيانات الاصطناعية بها.

## هيكلية المشروع

```
skin_cancer_project/
├── database/
│   ├── create_db.py      # إنشاء الجداول التسعة
│   ├── seed_data.py       # توليد بيانات اصطناعية واقعية النسب
│   └── skin_cancer.db     # قاعدة البيانات (تُنشأ بعد تشغيل السكربتين أعلاه)
├── src/
│   ├── 01_data_exploration.py   # استكشاف HAM10000 الحقيقية (يعمل في Colab)
│   ├── 02_preprocessing.py      # تجهيز الصور + Data Augmentation
│   ├── 03_model_train.py        # بناء وتدريب نموذج CNN (Transfer Learning)
│   └── 04_predict.py            # تنبؤ وحفظ النتيجة في قاعدة البيانات
├── app.py                 # واجهة استخدام (Streamlit) بالعربية RTL
├── docs/
│   └── system_analysis.docx     # وثيقة تحليل وتصميم النظام الكاملة
└── requirements.txt
```

## طريقة التشغيل

```bash
# 1) تثبيت المتطلبات
pip install -r requirements.txt

# 2) إنشاء قاعدة البيانات (الجداول فقط)
python database/create_db.py

# 3) تعبئة بيانات تجريبية (اختياري - للعرض والاختبار)
python database/seed_data.py

# 4) تشغيل واجهة الاستخدام
streamlit run app.py
```

## قاعدة البيانات: 9 جداول

`users` (أطباء) · `patients` (مرضى) · `lesion_types` (مرجع الفئات السبع) ·
`images` (الصور) · `model_versions` (إصدارات النموذج ودقتها) ·
`diagnosis_results` (نتائج التحليل) · `appointments` (مواعيد المتابعة) ·
`treatments` (خطط العلاج) · `audit_log` (سجل تدقيق العمليات)

بعد التشغيل الافتراضي: 60 مريضاً، 113 صورة، 113 نتيجة تحليل، 25 موعد متابعة،
17 خطة علاج، 60 سجل تدقيق، موزّعة بنفس نسب عدم توازن HAM10000 الحقيقية.

## الخطوات القادمة

1. تحميل صور HAM10000 الفعلية من Kaggle/ISIC Archive.
2. استبدال البيانات الاصطناعية ببيانات حقيقية (مع الحفاظ على خصوصية أي بيانات مرضى فعليين).
3. تدريب النموذج فعلياً عبر `03_model_train.py` وحفظ النتائج في `model_versions`.
4. ربط `04_predict.py` بواجهة `app.py` لعرض نتائج حقيقية بدل النص التوضيحي الحالي.
